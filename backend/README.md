# Fundsroom Mini ERP + CRM

Mini ERP + CRM Operations Portal developed as part of the Fundsroom Full Stack Developer Technical Case Study.

## Tech Stack

### Frontend
- React
- TypeScript

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- PostgreSQL
- Prisma

## Modules

- Authentication & Role Management
- Customer CRM
- Product Management
- Inventory Management
- Sales Challan Management

## Project Structure

- `frontend` - React frontend
- `backend` - Node.js/Express REST API
